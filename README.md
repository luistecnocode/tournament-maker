# Tournament Maker

Aplicación web sencilla para crear y gestionar distintos tipos de torneos.

## Objetivo

Desarrollar una herramienta web que permita introducir participantes y generar automáticamente cuadros de torneo.

El primer formato será:

- Eliminación directa
- Sorteo aleatorio de participantes
- Gestión automática de rondas previas cuando el número de participantes no sea potencia de 2
- Cuadro visual
- Selección de ganadores y avance automático de rondas

## Arquitectura prevista

- Backend: Python + Flask
- Frontend: HTML, CSS y JavaScript
- Despliegue: Docker
- Control de versiones: Git + GitHub

## Tipos de torneo previstos

1. Eliminación directa
2. Liga
3. Fase de grupos
4. Doble eliminación
5. Sistema suizo
